Supabase 동기화

이 아카이브는 Supabase Auth의 사용자 ID를 기준으로 데이터를 구분합니다. 기존 Magic Link 계정을 사용 중이라면 새 계정을 만들지 말고, 로그인된 상태에서 아래의 비밀번호 설정 기능으로 전환하세요. 사용자 ID와 기존 클라우드 데이터는 그대로 유지됩니다.

로컬 저장 모드

Project URL과 Publishable key를 등록하면 클라우드 동기화를 사용할 수 있습니다.

계정
기존 계정은 이메일과 비밀번호로 로그인합니다. 기존 Magic Link 계정을 비밀번호 방식으로 바꾸려면 로그인된 기기에서 먼저 비밀번호를 설정하세요.
로그인 사용자현재 Supabase 사용자 ID를 그대로 사용합니다. 기존 캐릭터 데이터와 연결된 계정입니다.
기존 Magic Link 계정에서 이 기능을 사용하면 새 사용자를 만들지 않고 현재 계정에 비밀번호만 추가합니다.

캐릭터 DB CSV

현재 화면에 적용된 최신 DB를 CSV로 내보내고, 수정한 CSV를 다시 가져올 수 있습니다. id 열은 수정하지 마세요. 행 순서는 자유롭게 바꿔도 되며, 가져올 때 id를 기준으로 각 캐릭터에 반영합니다.

배포용 HTML에는 Project URL과 Publishable key만 포함되고, 현재 수치·메모·비밀번호 같은 개인 데이터는 포함하지 않습니다.
